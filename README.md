# Biblioteca Escolar GPE - Script SQL

Este repositório contém o script completo para a criação e população do banco de dados de uma Biblioteca Escolar.

## Estrutura do Projeto
- **`biblioteca_escolar_gpe.sql`**: Contém o DDL (Data Definition Language) para criar as 10 tabelas e o DML (Data Manipulation Language) para inserir 3 registros em cada uma.

## Modelo de Entidade-Relacionamento (MER)
O banco de dados foi modelado para gerenciar:
- Pessoas (Alunos e Autores)
- Livros (Títulos e Exemplares)
- Empréstimos
- Editoras e Cursos

## Como Utilizar o Script
Para rodar este banco de dados:
1. Instale um servidor MySQL.
2. Acesse o console ou cliente MySQL (ex: MySQL Workbench).
3. Execute todo o conteúdo do arquivo `biblioteca_escolar_gpe.sql`.
